# Project guidance

## Group interaction

- When a button inside a visual group opens a mode, editor, or panel, morph that same group container in place. Do not open a separate window or a detached sibling panel.
- App-level settings are the exception. Open them in the native macOS Settings window.
- Every morphed group state must have a visible X button and respond to Escape. Both must restore the group's previous state.
- Keep the icon and label columns aligned across every row in a group.
